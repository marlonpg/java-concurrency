🧠 1. What Concurrency Means

Define concurrency briefly: running multiple tasks seemingly at the same time to improve performance or responsiveness.

⚙️ 2. Threads

The foundation of concurrency in Java (Thread class, Runnable interface).

🧱 3. Problems with Manual Thread Management

Hard to control, debug, and scale.

Leads to issues like deadlocks, race conditions.

🚀 4. Executor Framework

Introduced in Java 5 (Executor, ExecutorService, Executors).

Simplifies thread management by handling thread pools.

⏳ 5. Future and Callable

Allow tasks to return results or throw exceptions asynchronously.

🔄 6. Synchronization and Locks

synchronized keyword, Lock interface, ReentrantLock, and ReadWriteLock.

🧩 7. Concurrent Collections

Thread-safe versions of standard collections, e.g. ConcurrentHashMap, CopyOnWriteArrayList.

⛓️ 8. Synchronization Utilities

Tools like CountDownLatch, Semaphore, CyclicBarrier, and Phaser for coordinating threads.

⚡ 9. Atomic Variables

Classes like AtomicInteger and AtomicReference for lock-free thread-safe operations.

🌐 10. CompletableFuture

Modern, non-blocking API for composing asynchronous computations (introduced in Java 8).
